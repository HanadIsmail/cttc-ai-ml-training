# 🤖 AI & Machine Learning Learning Journey

A practical learning repository documenting my one-month journey through Python, Data Analysis, Machine Learning, Natural Language Processing, Computer Vision, and Deep Learning.

This repository contains my notes, Python implementations, Jupyter Notebooks, exercises, experiments, and course projects — built at CTTC (Central Tool Room & Training Centre), Bhubaneswar.

---

## 📚 Course Overview

This repository is based on a one-month AI & Machine Learning training program covering:

- Python Fundamentals
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Data Preprocessing & Analysis
- Supervised Learning
- Unsupervised Learning
- Natural Language Processing
- Computer Vision
- Artificial Neural Networks
- Deep Learning
- Convolutional Neural Networks
- Machine Learning & Deep Learning Projects
